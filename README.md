# ESCORTinRoad

Plataforma web da ESCORTinRoad: transporte rodoviário, armazenagem e rastreamento de cargas.

🔗 **Produção:** https://escort-in-road-sigma.vercel.app

## Stack

React 18 · TypeScript · Vite · Tailwind CSS · React Router

## Estrutura do repositório

```
Front-End-Web/   aplicação web (React + Vite)
```

## Como rodar

Requisitos: Node.js 20+ e npm 10+.

```bash
cd Front-End-Web
npm install
npm run dev
```

Mais detalhes (scripts e estrutura de pastas) em [Front-End-Web/README.md](Front-End-Web/README.md).
